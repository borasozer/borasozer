## Recent work

Most of this is client work or an ongoing university project, so the code is private.

- **Sales and ERP data platform** (freelance, for a textile manufacturer). A Raspberry Pi on the company network syncs the ERP database (SQL Server) to Cloudflare Workers and D1. It holds about 186,000 invoices going back to 2017 and feeds the management dashboards and alerts.
- **AI fabric visualisation** (freelance, for a textile company). I compared three image-generation models on 72 scored renders, then built the multi-tenant web app, which is now in pilot.
- **Eatsalo** (final-year project). An AI nutrition tracker that estimates foods and nutrients from a meal photo. Supabase back end and TypeScript web app; the iOS app (Swift) is in progress.
- **Comsalo** (university group project, 85%). An AI interview platform built by a team of five, where I was the second-largest contributor. I wrote the Groq-to-Claude LLM fallback, the chat interview mode and the Stripe billing.

## Public repositories

- [Early detection of Alzheimer's disease](https://github.com/borasozer/alzheimer-early-detection-ml): ML pipeline in Python and scikit-learn on a synthetic dataset of 2,150 patients (SMOTE, 5-fold stratified GridSearchCV). The tuned Decision Tree reached 95.1% accuracy and 0.949 ROC AUC.
- [CookShare](https://github.com/borasozer/MyAndroidApp): Android recipe-sharing app in Java (MVVM, Retrofit, Supabase, Firebase Auth).
- [Student enrolment scheduler](https://github.com/borasozer/enrol-scheduler): Round Robin, Priority and multi-level feedback queue scheduling for student enrolment requests, in Java with Maven.
